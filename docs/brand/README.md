# ECR app icon

A price tag (export charges) with a palm-oil drop, in the app's brown, amber and cream.

| File | Use |
|---|---|
| `ecr-icon-square-512.png` / `ecr-icon-square.svg` | DWS Hub app registration (full-bleed square; the Hub rounds the corners) |
| `ecr-icon-512.png`, `-256`, `-128`, `-1024` | Rounded icon for slides, docs and other places that show it as is |
| `ecr-icon-64.png`, `ecr-icon-small.svg` | Bolder small version for 16–64 px |
| `ecr-icon.svg` | Master artwork |

The web app serves its own copies from `frontend/public/`: `favicon.ico` (16/32/48), `icon-small.svg` (browser tab),
`icon.svg` (header), `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` and `site.webmanifest`.
